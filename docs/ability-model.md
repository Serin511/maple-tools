# 어빌리티 목표 세트 전략 계산

## 입력과 종료 조건

`sets`는 우선순위가 있는 1~4개 완성 세트이고, 각 세트에는 서로 다른 세 옵션과 최소 수치를 지정한다. 물리적인 줄을 지정하는 입력이 아니다. 예를 들어 1순위 `[패시브 1, 보스 19, 상태 이상 10]`, 2순위 `[패시브 1, 보스 19, 공격력 30]`을 지정한다.

각 허용 순위 k마다 1~k순위 중 하나의 세 옵션을 만족할 때 종료하는 정책을 따로 계산한다. 세 옵션의 여섯 줄 배치를 모두 허용한다. 서로 다른 세트에서 옵션을 섞어 종료하지 않는다. 상위 순위의 효용에 임의의 가격을 붙이지 않는다. 따라서 사용자가 결과의 비용과 타협 정도를 비교해 허용 범위를 선택한다. 여러 세트가 동시에 성립하면 가장 높은 순위로 완료 비율을 집계한다.

`minGrade`는 옵션별 최소 등급이며 0=등급 무관(에픽 이상), 1=유니크 이상, 2=레전드리이다. 기존 저장값에 이 필드가 없으면 등급 무관을 유지한다. 예를 들어 `[패시브 1, 보스 20, 상태 이상 8 (유니크 이상)]`은 레전드리/레전드리/유니크 조합으로도 완료된다. 상태 이상 유니크 7은 미달이며 심연으로 수치를 높일 후보가 되고, 유니크 8 또는 레전드리 9 이상은 달성이다. 같은 종류·수치라도 순위 세트별 최소 등급은 독립적으로 판정한다.

레벨당 공격력/마력 옵션은 레벨 간격이 작을수록 좋으므로 **이하** 조건이다. 두 스탯 옵션은 주·부스탯 커트라인을 함께 받을 수 있다. 동일한 값이 여러 단계에서 등장하면 단계 확률을 합한다.

## 확률과 비용

사용자가 제공한 `메이플_명성치_어빌리티_확률.md` (2026-09-17 기준)를 전사했다. 2026-09-18에 아래 넥슨 원문과 대조했다.

- [명성치/고급 재설정/서큘레이터 확률표](https://maplestory.nexon.com/Guide/OtherProbability/ability/reputevalue)
- [어빌리티 게임 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/392)
- 가이드 내 심연의 서큘레이터 툴팁: 등급·종류 유지, 세 줄 수치 재설정, 기존 또는 신규 결과 적용 선택. 수치 유지도 가능하다.

41개 옵션 종류를 모두 모델링한다. 서큘레이터 전용 과거 옵션(방어력, 이동속도 등)은 새 고급 재설정으로 획득할 수 없으므로 시작 옵션이나 목표로 제공하지 않는다. 등급별 표기 가중치 합으로 정규화한다. 고정된 모든 옵션을 먼저 제외하고, 남은 줄을 1→2→3 순서로 뽑는다. 각 줄의 등급을 먼저 정한 후 **그 등급의** 제외 가중치를 분모에서 뺀다. 비목표 옵션을 뽑았을 때도 이후 줄의 중복 제외에 영향을 준다.

고정 0/1/2개 비용은 `명성치 20,000/30,000/40,000 + 메소 2,000,000/6,000,000/15,000,000`이다. 명성치 1점 비용은 훈장 가격 / 5,000, 심연 1개 비용은 4,900 × 100,000,000 / 메소마켓 시세이다. 기본 시세에서 고급 재설정 1회는 2,600만/4,200만/6,300만 메소, 심연 1개는 약 2.2273억 메소이다.

첫 유료 고정 없는 재설정부터 비용을 센다. 기존 명성치, 구입 제한, 마켓 수수료, 할인은 포함하지 않는다.

## 상태와 전체 행동 공간

각 줄은 옵션 종류, 목표 달성 가능 여부에 영향을 주는 등급, 커트라인별 충족 비트 집합으로 표현한다. 서로 다른 순위에서 같은 종류에 다른 수치를 요구하면 각각을 구분한다. 비목표 종류는 에픽·유니크·레전드리 가중치가 모두 같은 종류끼리만 묶고, 묶음의 실제 옵션 수를 보존한다. 묶음에서 이미 선택된 개수를 차감하므로 중복 제외 확률은 보존된다. 목표와 무관한 등급/수치는 합산하며, 심연으로도 목표 커트라인에 도달할 수 없는 등급은 별도 상태로 표현한다.

각 상태에서 다음을 모두 비교한다.

- 고정 마스크 `000`~`110`: 0개 고정, 세 종류의 1개 고정, 세 종류의 2개 고정
- 심연 사용: 각 줄의 종류·등급을 보존하며 값 분포의 곱으로 세 줄 모두 재설정
- 새 세 줄 전체 채택 또는 기존 세 줄 전체 유지
- 목표 달성 시 종료

이전 고정 옵션을 계속 고정한다는 제약은 없다. 비목표 옵션 임시 고정, 목표 후보 폐기, 수치 충족→미달, 타협 세트→다른 세트 교체, 서큘레이터→고급 재설정 복귀도 가능하다. 세 줄의 값을 개별적으로 골라 합치는 행동은 없다. 목표 종류를 모두 모은 후 서큘레이터를 쓰는 비교 정책은 **서큘레이터 결과에서 완성 세트가 실제로 가능한 상태**에서만 사용을 허용한다.

## 최적화

V(s)를 목표까지 남은 최소 기대 메소, c(a)를 행동 비용, P(a,t)를 새 상태 t가 나올 확률이라고 하면:

```
V(goal) = 0
V(s) = min_a [ c(a) + sum_t P(a,t) * min(V(s), V(t)) ]
```

고정 내용이 같으면 행동의 결과 분포가 같으므로 분포를 공유한다. 목표 상태부터 남은 비용의 오름차순으로 상태와 행동을 확정하는 stochastic Dijkstra를 사용한다. 이미 확정된 더 좋은 결과만 채택할 때 행동의 제안 비용은 다음과 같다.

```
offer(a) = (c(a) + sum_accepted P(a,t) * V(t)) / sum_accepted P(a,t)
```

다음 미확정 상태보다 제안 비용이 먼저 나왔으면 이후 결과를 채택할 이유가 없으므로 그 제안은 확정된다. 모든 비용은 양수다. 채택 전이는 V가 엄격히 감소하므로 정책의 기대 소모량과 종료 분포는 순서대로 계산할 수 있다. 표시하는 행동 비교는 해당 행동 **한 번** 수행 후 최적 정책을 따를 때의 추가 비용이다.

부동소수점 동률은 절대 0.00001 메소, 상대 1e-12 이내에서 개선으로 보지 않는다. 동률 전략의 서로 다른 서큘레이터 시점은 모두 같은 최적 비용일 수 있다. 몬테카를로 표본을 사용하지 않는다.

## 동일 결과 재추첨: 명시적인 근사와 비용 범위

공식 고급 재설정의 완전 동일 결과 재추첨은 실제 이전 세 줄의 종류·등급·정확한 값에 따라 달라진다. 기본 입력에 현재 비목표 수치가 없고 상태를 커트라인별로 압축하므로 대표 엔진에서는 이 재추첨만 생략한다. 반올림 확률로 구성한 모델의 최적 정책이며, 실제 게임의 정확한 모든 미시 상태 최적 정책이라고 주장하지 않는다.

단순히 오차가 작다고 가정하지 않고 하한·상한을 계산한다. 고정되지 않은 줄마다 `등급 확률 × 종류 확률 × 단일 값의 합산 확률`의 상한을 구한다. 중복 제외의 분모는 해당 종류를 제외한 가장 무거운 두 종류를 빼서 하한을 잡는다. 미고정 줄별 상한의 곱 ε(a)는 어떤 기존 정확한 세 줄이든 다시 나올 확률의 상한이다.

동일 결과 확률이 r(s,a)일 때, 같은 Bellman 식에서 재추첨은 비용을 `c(a) * (1-r(s,a))`로 바꾼 것과 같다. `0 ≤ r ≤ ε`이므로:

- 상한: 재추첨 생략 비용 c(a)의 모델 최적값
- 하한: 모든 재설정 행동의 비용을 c(a)(1-ε(a))로 낮춘 모델 최적값

옵션 묶음 내 정확한 상태마다 비용이 달라도 하한 비용은 항상 그 이하이므로 두 결과는 실제 세부 상태 모델의 최적값을 감싼다. 서큘레이터는 공식 툴팁의 수치 유지 가능 규칙에 따라 동일값을 허용하며 비용을 줄이지 않는다. 확률표 자체의 반올림 오차까지 보장하는 구간은 아니다. 구간 안에서는 세부 행동의 최적 순위가 바뀔 수 있으므로 화면에서 명시한다. 소모량과 전환 비율은 상한 대표 정책의 값이다.

## 자동 재설정 등록 안내

고정 없는 고급 재설정을 추천할 때와 최초 시작 안내에 자동 재설정의 옵션·등급·입력 수치 및 ‘첫 줄 제외’ 권장값을 표시한다. 공식 가이드의 최대 6개 유니크/레전드리 등록 조건과 단일 옵션 일치 시 중단하는 규칙을 따른다. 이 안내는 기존 최적 정책과 비용 계산을 바꾸지 않는다.

현재 상태보다 V가 작은 **모든** 고정 없는 재설정 결과를 대상으로 종료조건을 만든다. 각 목표 종류·등급의 유용한 결과에서 등장하는 최저 원시 수치를 등록 후보로 쓴다. 최종 커트라인에 못 미쳐도 심연을 통해 개선할 수 있으므로 예를 들어 보스 20% 목표에서 레전드리 보스 15%를 등록할 수 있다. 레벨당 능력치도 등록은 원시 수치 이상의 넓은 조건으로 잡고, 최종 레벨 간격 이하 달성 여부는 별도 확인하도록 안내한다. 두 스탯 옵션도 최종 두 커트라인 판정은 세 줄 상태 조회에서 수행한다.

‘첫 줄 제외’ 끄기와 켜기를 각각 계산한다. 유용한 결과마다 등록 후보의 집합을 만들고, 최대 6개 조건으로 모든 집합을 적어도 한 번씩 덮는 조합을 탐색한다. 가능한 완전한 조합 중 등록 개수를 줄이고, 같은 개수에서는 불필요한 중단이 적은 쪽을 권장한다. 해당 등급·수치가 맞는 결과를 전부 포착하는 보수적인 덮개이며, 상위 등급에서도 중단되는 등 게임에서 추가 중단이 발생할 수 있으므로 중단 확률을 UI에 표시하지 않는다. 후보 수치를 더 세밀하게 조정하는 모든 자동 설정 조합의 전역 최적성을 주장하지 않는다.

등록 한도를 넘으면 필요한 후보를 생략하지 않고 전부 표시하며 동시에 등록할 수 없음을 알린다. 에픽만으로 가치가 개선되는 등 등록 후보로 잡을 수 없는 결과가 있으면 자동 진행을 권장하지 않는다. 한도 안의 완전한 덮개를 찾지 못했을 때는 타협 범위를 줄이거나 직접 결과를 확인하도록 안내한다. 자동 중단은 세 줄 전체 채택을 의미하지 않는다. 멈춘 세 줄을 상태 선택기에 입력해 남은 비용을 비교하고 개선되는 경우에만 채택한다.

## UI / 빌드

기존 잠재능력 페이지는 그대로 두고 `#/ability`에 페이지를 추가한다. 설정은 별도 localStorage 키에 저장한다. 새 설정은 재계산 전 과거 결과를 숨겨 잘못 연결하지 않는다. 계산은 Blob Web Worker에서 수행한다. 새 계산은 이전 Worker를 종료하고 오래된 응답을 무시한다.

기존 GitHub Pages 빌드와 단일 HTML 전달 형식을 유지한다. CSS와 Worker 소스를 `dist/index.html` 안에 포함하므로 추가 경로나 SPA 서버 rewrite 없이 파일 직접 열기 및 GitHub Pages 해시 경로에서 사용할 수 있다.
