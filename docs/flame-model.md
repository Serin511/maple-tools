# 추가옵션 효율 계산기

## 적용 범위와 입력

`#/flame`은 보스 방어구·장신구의 메소 추가옵션 재설정을 계산한다. 일반 모드는 한 종류의 주스텟과 한 종류의 부스텟, 공격력 또는 마력, 올스텟%를 평가한다. 주스텟·부스텟 입력은 단일 스텟과 이중 스텟 추가옵션을 합한 최종 증가량이다. 공격력과 마력 중 자신의 직업에 유효한 한 종류만 입력한다. 제논 모드는 STR·DEX·LUK·공격력·올스텟%를 함께 평가한다.

계산 대상은 방어구·장신구로 한정하며 무기는 제외한다. 일반 장비의 옵션 개수·등급 분포와 데몬어벤져 등의 별도 효율 체계는 포함하지 않는다. 추가옵션 장사 도구에도 제논 모드는 적용하지 않는다.

일반 모드의 효율 입력은 주스텟 10당 1%, 부스텟 10당 0.1%, 공격력·마력 10당 3%, 올스텟 1%당 1.1%가 기본이다. 예를 들어 주스텟 100, 부스텟 50, 공격력 10, 올스텟 5%는 기본 효율에서 `10 + 0.5 + 3 + 5.5 = 19%`로 평가한다. 사용자의 효율은 이미 계산된 주스텟% 환산 비율로 취급하며 캐릭터의 실제 데미지를 다시 계산하지 않는다.

일반 모드의 추천 중단점은 주스텟 수치로 환산한 **급수**로 표시한다. 주스텟 10당 효율을 e라고 할 때 `급수 = 주스텟% 환산값 * 10 / e`이다. 기본 효율에서는 `주스텟 + 부스텟 * 0.1 + 공격력·마력 * 3 + 올스텟% * 11`이며, 위 예시는 190급에 해당한다. 주스텟 효율을 바꾸면 급수 환산 비율도 함께 바뀐다. 소수 급수를 유지해 정수로 반올림한 값이 계산상 중단점을 바꾸지 않도록 하며, 주스텟%는 보조 정보로 표시한다. 주스텟 효율이 0이면 주스텟 수치로 환산할 수 없어 주스텟%로 표시한다.

### 제논 모드

제논은 `STR`, `DEX`, `LUK`, 공격력, 올스텟%의 현재 증가량을 각각 입력한다. INT와 마력의 환산 가치는 0이지만 해당 옵션 종류도 실제 추가옵션 선택 풀에는 남는다. 이중 스텟 옵션은 포함된 두 유효 스텟 모두에 증가량을 더한다.

제논의 효율은 STR·DEX·LUK·공격력 각각 10당 올스텟 환산 효율로 입력하며, 올스텟 1%는 고정 기준 1이다. 기본 참고값은 STR 0.5, DEX 0.5, LUK 0.5, 공격력 2.5, 올스텟 1이다. 이는 커뮤니티 예시인 올스텟 1% = 주스텟 합 20, 공격력 1 = 주스텟 합 5를 올스텟 1% 기준으로 환산한 값이다. 참고 사례이며 공식 기준이나 특정 캐릭터의 최적 효율을 뜻하지 않는다. STR·DEX·LUK·공격력 효율은 사용자가 변경할 수 있고 올스텟 효율 1은 고정 기준이다.

올스텟 환산 점수는 `STR/10*eS + DEX/10*eD + LUK/10*eL + 공격력/10*eA + 올스텟%`이다. 여기서 `eS`, `eD`, `eL`, `eA`는 각 입력 효율이다. 가격 입력 단위는 **올스텟 1% 환산 점수당 지불할 최대 메소**다.

STR·DEX·LUK 효율이 같은 양수 `e`일 때만 급수를 `환산 점수 * 10 / e`로 표시한다. 이때 식은 `STR + DEX + LUK + 공격력*eA/e + 올스텟%*10/e`이다. 세 주스텟 효율 중 하나라도 서로 다르거나 0이면 급수를 표시하지 않고 올스텟 환산 점수만 표시한다. 예를 들어 200제 장비에서 현재 증가량이 STR 36, DEX 72, LUK 36, 공격력 5, 올스텟 6%이면 기본 참고값에서 `14.45` 올스텟 환산 점수, `289급`이다.

기본 참고값의 근거는 [커뮤니티 환산 예시](https://www.inven.co.kr/board/maple/2304/33070)이며, 개인 효율이 다를 수 있는 사례는 [제논 유저의 효율 조정 예시](https://m.inven.co.kr/board/maple/2298/229188?vtype=mobile)를 참고한다. 직업 정보는 [공식 제논 가이드](https://gi.maplestory.nexon.com/Guide/Character/Xenon)를 참조한다.

## 비용과 확률

2026년 3월 19일 공식 업데이트는 메소 추가옵션 재설정 비용을 레벨과 무관하게 **3,000,000 메소**로 명시한다. 기존 옵션과 신규 옵션을 선택할 수 있고 옵션 등장 확률은 검은 환생의 불꽃과 같다.

- [공식 2026년 3월 19일 업데이트](https://maplestory.nexon.com/News/Update/799)
- [공식 추가옵션 확률표](https://maplestory.nexon.com/Guide/OtherProbability/game/gameAddOption)

보스 장비는 서로 다른 옵션 종류 4개를 균등하게 선택한다. 각 옵션의 등급은 4·5·6·7등급이 각각 29%·45%·25%·1%이다. 방어구·장신구의 기본 옵션 종류는 19개이며, 레벨 제한으로 등장할 수 없는 종류는 옵션 풀에서 제외한다.

제논 모드도 보스 장비의 서로 다른 옵션 종류 4개와 등급·수치 생성 규칙을 공유한다. 제논 점수에 기여하지 않는 INT·마력 등도 옵션 풀에 남으며, 옵션 선택에서 빠뜨리지 않는다. 기존 250제 에테르넬 단일 스텟 예외도 그대로 적용한다.

레벨 제한을 L, 등급을 t라 할 때 단일 스텟은 일반적으로 `(floor(L/20)+1)*t`, 이중 스텟은 `(floor(L/40)+1)*t`이다. **250제 에테르넬 방어구의 단일 스텟은 예외적으로 `12*t`**이며, 4~7등급에서 48·60·72·84이다. 이 예외는 단일 주스텟과 단일 부스텟 모두에 적용한다. 250제 이중 스텟은 일반식대로 `7*t`(28·35·42·49)이다. 공격력·마력 증가량과 올스텟%는 t이다. 레벨 제한은 기본 레벨을 사용하며 착용 레벨 감소 추옵을 차감하지 않는다. 일반 수치 공식은 [추가옵션 수치 해설과 표](https://www.inven.co.kr/board/maple/2304/27668)를 참고하며, 250제 수치는 [에테르넬 추옵 표](https://meaegi.com/simulator/add-option/에테르넬%20메이지햇)와 사용자 확인을 반영한다.

평가에 무관한 옵션도 선택 확률에 포함한다. 유효 옵션의 부분집합을 열거한 뒤 남는 칸을 무효 옵션으로 채우는 조합 수로 가중하고, 유효 옵션의 등급을 모두 열거한다. 같은 유효 스텟 합계의 확률은 합산하되 서로 다른 종류의 중복 선택은 허용하지 않는다.

공식 시스템은 **직전과 완전히 같은 결과를 제외하고 재추첨**한다. 현재 입력은 유효 스텟의 합계만 받아 무효 옵션과 각 옵션 등급을 복원할 수 없으므로, 계산은 이 재추첨을 생략한 독립 시행 모델을 사용한다. 따라서 중단점과 기대 비용은 이 기본 분포 모델의 결과이며, 게임의 완전한 상태별 정밀 계산과는 경계에서 차이가 날 수 있다. 같은 환산 점수의 서로 다른 조합은 정상 결과이므로 제외하지 않는다.

## 최적 중단 방정식

추가옵션의 모드별 환산 점수를 X, 1회 재설정 비용을 c, 환산 점수 1단위당 지불할 최대 메소를 v라 한다. 일반 모드 점수는 주스텟% 환산값이며, 제논 모드 점수는 올스텟% 환산값이다. 최종 스텟의 가치 `v*X`에서 향후 재설정 비용을 뺀 기댓값을 최대화한다. 이미 쓴 비용은 중단 판단에 포함하지 않는다. 중단 방정식과 최적화 방식은 양 모드에서 같다.

중단 경계 t는 다음 식을 만족한다.

```
v * E[max(X - t, 0)] = c
```

현재 점수가 t 이상이면 중단한다. 낮으면 재설정을 계속하면서 더 높은 결과를 유지하고, t 이상의 결과가 나올 때 중단한다. 실제로 등장 가능한 점수 중 t 이상인 최솟값을 화면의 목표 중단점으로 표시한다. 정확히 같은 가치라면 추가 비용 없이 중단하는 쪽을 선택한다. 지불 의향이 0이면 바로 중단한다.

목표에 도달할 확률을 q라 하면 현재 상태에서 계속하는 경우 기대 횟수는 `1/q`, 기대 비용은 `c/q`, 최종 점수는 `E[X | X >= t]`이다. 현재 상태에서 중단하면 향후 기대 횟수·비용·상승량은 0이다. 기대 횟수와 비용은 평균이며 최대 소모량이 아니다. 총예산·기간·일일 제한은 입력하지 않는 무한 기간 모델이다.

## 설정 저장과 검증 범위

설정은 `maple:flame:settings:v2`에 모드별 프로필로 저장하며, 일반·제논 모드의 입력과 효율을 서로 분리한다. 기존 v1 설정은 보존하고 일반 모드 프로필로 이전한다. 비어 있는 입력값은 저장·복원 시에도 빈 값으로 유지한다. 설정 변경 시 이전 결과를 숨기며 재계산은 이전 Worker를 종료한다. Worker와 CSS는 기존 어빌리티와 동일하게 단일 `dist/index.html`에 포함하므로 GitHub Pages 해시 경로와 파일 직접 열기에서 동작한다.

`npm test`는 기존 일반 모드 결과 보존, 제논 효율 환산과 급수 표시 조건, INT·마력 및 이중 스텟의 옵션 풀·기여도, 250제 예외, 설정 이전과 모드별 빈 입력 보존, 공유 중단 방정식, 확률 모델과 입력 오류를 검사한다. `npm run build`는 배포용 HTML을 생성한다.
